## 📌 About This Repository
This repository showcases my practical work and academic projects in **Database Systems (CSC 380)**. It serves as an archive of my journey in mastering database concepts, from initial schema design and entity-relationship modeling to writing complex SQL queries and integrating databases with applications.

## 🗂️ Repository Structure
The repository is logically organized to reflect the database development lifecycle:

*   📁 **`Entity-Relationship-Diagrams/`**: Conceptual and logical database designs (ERDs) and schema architectures.
*   📁 **`SQL-Queries/`**: Scripts containing DDL (Data Definition Language) and DML (Data Manipulation Language) commands, including complex joins and subqueries.
*   📁 **`Projects/`**: End-to-end database projects, demonstrating practical applications and database integration.

## 💡 Why This Matters?
A robust database is the core of any functional application. Mastering database design and querying is not only essential for software development but is also a critical foundation for **Cybersecurity**. Understanding how data is structured and accessed is the first step in identifying vulnerabilities (like SQL Injection) and securing sensitive information.
